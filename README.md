# Portafolio profesional de Octavio Palafox

Esta versión separa la estructura, los estilos y la interacción en tres archivos para que sea más fácil de mantener:

- `index.html`: contenido, estructura semántica y metadatos para buscadores.
- `styles.css`: diseño adaptable a celular, accesibilidad y respeto por preferencias de movimiento reducido.
- `script.js`: menú móvil, animaciones opcionales y año automático.

## Antes de publicar

1. Reemplaza la foto alojada en Postimages por una copia dentro del repositorio, por ejemplo `assets/octavio-palafox.jpg`, y actualiza el atributo `src` en `index.html`.
2. Añade URL canónica y las etiquetas `og:image` cuando definas el dominio final y la imagen para compartir en redes.
3. Sustituye las responsabilidades por resultados medibles cuando tengas las cifras confirmadas. No inventes métricas.

Para publicar esta versión en GitHub Pages, sustituye los archivos del repositorio por estos tres archivos y haz commit a la rama configurada para Pages.
